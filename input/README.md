# Input

The runnable beginner source is `examples/local_project/` at the project root.
From that root, run:

```console
metrolith analyze examples/local_project --workspace ../metrolith-demo
```

After installation, `metrolith example run --local` uses the same packaged
sample. Generated results go to the printed Run directory. Put your own CSV
lists here only when using `metrolith run --input input/repositories.csv`;
no research lists or generated outputs are included.

See [USAGE](../docs/USAGE.md) for input and source-state guidance.
